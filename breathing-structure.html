01 — Background
01
개념과 출발점

기하학적 형태가 유기적으로 팽창·수축합니다.

규칙적인 기하학 구조물에 사인파 기반 스케일 변형을 적용했습니다. React 컴포넌트 안에서 Three.js 씬을 관리하고, requestAnimationFrame 루프로 지속 애니메이션됩니다.

Concept

기하학적 형태가 유기적 움직임을 가지면 구조 자체가 살아있는 것처럼 인식됩니다.

01

애니메이션 주기

사인파 기반 팽창·수축입니다. 진동 주기와 진폭은 시지각에서 '호흡'으로 인식되는 임계값을 기준으로 조정했습니다.

02

지오메트리 선택

폴리곤 수가 많은 복잡한 메시는 변형의 윤곽이 불분명해집니다. 구·토러스 중심의 단순 지오메트리를 사용해 스케일 변형이 즉각 인식되도록 했습니다.

03

공간감

FogExp2와 방향성 조명(DirectionalLight)을 조합해 2D 평면이 아닌 3D 공간감을 부여했습니다.

02 — Technical Design
02
기술 설계

React 안에서 Three.js 씬을 관리합니다.

useEffect로 마운트 시 씬을 초기화하고, requestAnimationFrame 루프를 컴포넌트 생명주기에 연결했습니다. 언마운트 시 renderer와 geometry를 정리해 메모리 누수를 방지합니다.

01

Vite HMR

HMR로 씬 파라미터를 실시간 수정·확인합니다. 렌더링 순서나 애니메이션 파라미터 튜닝 주기가 빠릅니다.

02

Three.js

조명·지오메트리·카메라 컨트롤·안개를 Three.js API로 일괄 처리합니다. WebGL 셰이더를 직접 작성하지 않아도 필요한 렌더링 파이프라인을 구성할 수 있습니다.

03

애니메이션 루프

requestAnimationFrame마다 Date.now() 기반 시간값을 사인파에 입력해 구조물 스케일을 갱신합니다. 입력 없이도 지속 애니메이션됩니다.

04

Vercel 배포

Vite 빌드 후 Vercel에 배포합니다. WebGL 기반이기 때문에 브라우저만 있으면 별도 런타임 없이 실행됩니다.

04 — Outcome

Runs in the browser. No install.

마우스로 카메라 회전·줌 조작이 가능하고, 구조물은 입력 없이 사인파 기반으로 지속 애니메이션됩니다.

인터랙션

OrbitControls + 자율 애니메이션

OrbitControls로 카메라 회전·줌·패닝을 지원합니다. 구조물은 사용자 입력 없이 requestAnimationFrame 루프에서 사인파로 지속 변형됩니다.

배포

Vercel — 브라우저에서 즉시 실행

WebGL 기반입니다. 브라우저만 있으면 별도 런타임 없이 실행되며, URL로 즉시 공유됩니다.

구조

React–Three.js 렌더 루프 통합

useEffect 기반 씬 초기화·루프 관리·클린업 패턴입니다. React 생명주기와 WebGL 렌더 루프를 통합할 때 발생하는 메모리 관리 이슈를 처리했습니다.

결과

기하학 구조물의 유기적 움직임

규칙적인 기하학 형태가 사인파 기반 스케일 변형을 통해 유기적인 것처럼 인식되는 효과를 구현했습니다.

Reflection

"기하학적 형태는 정적일 때보다
움직일 때 더 많은 것을 이야기한다."

정적 오브젝트와 움직이는 오브젝트의 차이는 기술이 아니라 인식에 있습니다. 같은 구라도 팽창·수축이 더해지면 살아있는 것처럼 읽힙니다. React와 Three.js의 통합 구조는 씬의 재사용성과 상태 관리 측면에서 명확한 장점이 있습니다.
